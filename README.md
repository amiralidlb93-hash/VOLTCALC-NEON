# ⚡ VOLTCALC

A calculator that looks like it was pulled out of a cyberpunk arcade.

Glowing neon rim, chunky 3D keys, a panel that tilts as you move your mouse,
and a display that burns cyan. Built with pure HTML, CSS and vanilla JS.
No frameworks, no dependencies, just one file.

## Features
- 3D tilt effect that follows your cursor or touch
- Animated neon glow with a rotating gradient rim
- Add, subtract, multiply, divide, percent, plus/minus, backspace
- Full keyboard support (0-9, + - * /, Enter, Backspace, Esc)
- Division-by-zero protection
- Responsive, works on desktop and mobile
- Respects reduced-motion settings

## Usage
Open `index.html` in any modern browser. That's it.
